# M3 — Rotor surrogate from scarce data: formulation card

**Question.** What is the rotor figure of merit FM as a function of rotor diameter D and thrust per rotor T, built from at most 30 expensive oracle runs, so that M1 can stop assuming FM0 = 0.65?

**Decision variables:**

- *Where to sample:* 30 (D, T) points in 3 requests (15 + 9 + 6), **continuous**, D 0.35–0.80 m, T 8–40 N
- *Which surrogate:* **categorical**: quadratic, thin-plate RBF, cubic RBF, GP with ARD + nugget
- inputs are (D, T) scaled by the oracle box; disk loading DL = T/(πD²/4) is used only to read the results

**Objectives:**

- O1 lowest prediction error at points the model has not seen (RMSE in FM units is the headline, Q² secondary)
- O2 most accuracy where M1 needs FM: the loaded and empty hover thrust of designs A–E

**Constraints:**

| # | Constraint | Number |
|----|--------------------------|--------------------------------------------------|
| C1 | oracle budget | ≤ 30 runs in ≤ 3 requests, all inside the oracle box |
| C2 | spacing of new points | ≥ 0.10 (scaled) from existing points, except a deliberate repeat |
| C3 | use in M1 | FM evaluated only inside the convex hull of the sampled points |

**Method:**

- *Request 1:* maximin Latin hypercube, a space-filling start
- *Requests 2 and 3:* scored greedy picks, split exploit / explore / random / repeat = 3/3/2/1 and 2/3/1/0. Exploit score = closeness to the M1 hover points × GP σ; explore score = 0.7σ + 0.3|RBF − GP|
- models compared by LOO, repeated 5-fold CV and true hold-out on each later request, with predictions frozen before sending
- *Choice:* cubic RBF, passed to M1 and every later module

**Result (30 runs, 29 unique points):**

| Model | LOO RMSE | 5-fold RMSE | final hold-out RMSE |
|--------------------|--------------|------------------|--------------------|
| quadratic | 0.078 | 0.084 ± 0.011 | 0.088 |
| thin-plate RBF | 0.037 | 0.046 ± 0.011 | 0.059 |
| **cubic RBF** | 0.041 | 0.051 ± 0.010 | 0.051 |
| GP (ARD + nugget) | 0.041 | 0.058 ± 0.018 | 0.044 |

- where M1 operates (DL 40–110): cubic RBF LOO RMSE 0.017; hold-out RMSE 0.007 at the two request-3 points next to designs C and D
- with the real FM, M1 take-off mass rises by 4–8 % and rotors shrink (design C: 0.78 → 0.68 m); request 3 moved the optimum by < 1 %
- *Final design set (surrogate FM + M2 plate), used in M4–M7:* A 7.08, B 8.49, C 10.73, D 11.64, E 15.19 kg snapped (results/m1_fm_designs.csv)

**Verification:** final LOO / 5-fold / hold-out error table and parity plot (results/m3_final_error_table.csv, figures/m3_loo_parity_final.png); noise note; local error check in the M1 region (results/m3_local_error_M1_region.csv).

**Key assumptions and data issues handled:**

- *Noise:* about 0.003 from one repeated pair (0.4683 / 0.4730), more than 10× below the model errors, so the oracle is treated as practically deterministic and the RBFs interpolate exactly; repeats are averaged before fitting and CV (30 runs → 29 points)
- *FM depends on (D, T) only*, as the brief states; (log DL, D) inputs were tried and not adopted
- *Cubic RBF over the others:* no test gives a clear winner (LOO, 5-fold and hold-out rank differently, within the 5-fold spread), and M1 does not care: thin-plate or GP change masses by ≤ 1.6 % and give the same snapped designs except D (11.61 vs 11.64 kg). The GP is kept only for σ maps
- *Cliff:* FM above DL ≈ 180 (0.69 → 0.20) is not trusted; C3 keeps M1 out (inactive at every optimum, designs sit at DL 40–110)
- *Adaptive picks:* score weights, Gaussian width 0.08, design-C weight 1 vs 0.6, spacing 0.10 and seeds 6002/6003 are hand-chosen, not tuned
- *Data issue:* the request-1 LHS notebook prints points that differ from result_1.csv; result_1.csv is taken as the source of truth
